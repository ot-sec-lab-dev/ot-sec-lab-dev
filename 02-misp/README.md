\# MISP - Malware Information Sharing Platform



\## Objective



Deploy a self-hosted MISP instance using Docker Compose as the central Threat Intelligence Platform of the OT/ICS Threat Intelligence Lab.



This module will demonstrate:



\- Deployment of MISP using Docker

\- Initial platform configuration

\- Event creation

\- IOC management

\- Tagging and classification

\- Export and sharing capabilities

\- Integration with n8n
